# Farhad Hossain

I'm an MS student in Informatics at Penn State (expected December 2026). Before that I spent about three years at Cefalo building web applications with Java, Kotlin, Spring Boot, Angular and React.

I study how people use AI agents and what LLMs reveal about people.

### Current work

- A course research project evaluating a small computer-use agent (Qwen3-4B) on MiniWoB++ web tasks on one laptop.
- Measuring whether relationships between third parties survive when an LLM rewrites a text to anonymize it, supervised by Dr. Anna Squicciarini with Dr. Sarah Rajtmajer.
- In May 2026 I proposed a study of when developers turn off coding-agent approval prompts, and how different prompts affect their reviews.

### Projects

- [SearchSensei](https://github.com/mfarhadhossain/SearchSensei): a Chrome prototype that uses OpenAI to flag sensitive terms in a search query and lets you review edits before searching.
- [Swadesh](https://mfarhadhossain.github.io/project/swadesh/): an on-device iPhone app that tells me who I haven't talked to in a while. It looks for a reminder time that works in both time zones, and if it can't find one, it stays within my calling window.
- [Birb AI](https://mfarhadhossain.github.io/project/diet-assistant/), a diet assistant: a Telegram bot that estimates calories and macros from meal descriptions and lets the user confirm before saving.
